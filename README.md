Superstore Sales Analysis Using Python

Project Overview

This project analyses retail sales data to understand sales performance, profitability, product categories, regions, and shipping methods.

Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

Project Tasks

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Sales and profit analysis
- Regional and product performance analysis
- Created 10 data visualisations
- Generated business insights

Visualisations

1. Sales by Category
2. Monthly Sales Trend
3. Top 10 Products by Sales
4. Sales by Region
5. Profit by Category
6. Discount vs Profit
7. Sales Distribution by Region
8. Quantity Distribution
9. Sales by Ship Mode
10. Sales vs Profit

Conclusion

This project demonstrates practical Python skills in data cleaning, exploratory data analysis, and data visualisation to identify retail sales trends and business insights.
